# Known Limitations

## Phase 1 demo

- **No real authentication.** The role switcher is a UI demonstration, not auth. `localStorage` stores the active demo role.
- **No real database.** Mock data lives in memory and resets when the server restarts.
- **Audit logs are not tamper-proof.** They are in-memory only. A future decentralized verification layer is planned but not deployed.
- **Mock AI is deterministic.** No real AI provider is called. Suggestions are generated by a clearly-labeled deterministic function.
- **Mock votes are not secure.** A `localStorage` flag prevents accidental duplicate demo votes within a session — this is not a real vote-integrity control.
- **No real-time updates.** Changes are reflected on next page load, not via WebSocket. Socket.io is available but unused in Phase 1.
- **Persian (RTL) localization is partial.** The architecture supports RTL; full translation is deferred. The toggle works in Settings, but most UI strings remain English.
- **Light theme is not exposed in UI.** The CSS variables exist; the toggle is disabled in Settings.
- **Charts (recharts) are available but not used.** Dashboards use numeric StatCards and tables instead of charts in Phase 1.
- **Production build via `next build` was not executed in this sandbox.** The dev server compiles all routes successfully; lint and unit tests pass. A full standalone build should be run before any deployment.
